# CLAWDIA

Official website for **CLAWDIA**, a novel by Frederic Cornaille, published by [Thin Line Press](https://thinlinepress.com.au).

Live site: <https://clawdia.thinlinepress.com.au> (English) and <https://clawdia.thinlinepress.com.au/fr/> (French edition, *Clawdia : Elle ne vous lâche jamais*).

## What this repository is

A static, bilingual (EN/FR) site served by GitHub Pages. There is no framework, no analytics or tracking script and no server-side code. The pages are plain HTML, CSS and a small amount of JavaScript. Fonts are loaded from Google Fonts.

```
index.html     English page
fr/            French page
assets/        Stylesheet and script
cover.jpg      English cover
cover-fr.jpg   French cover
CNAME          Custom domain
robots.txt, sitemap.xml
```
